# Heart-Failure-Final-Project
final project for STAT 4000

We used code from both files on our final project. We performed logistic regression with all predictors twice (once in each file) and got slightly different results on each, so we used the one from 'Heart_Failure_Final_Project' in our actual analysis. Either way we get the same result. 

The % change between survived and died is in 'heart_failure_project' while most everything else is in the other file.

When checking the coefficient values after logistic regression with the lasso, there are 4 non-zero coefficients, however the first coefficient is just the intercept, which we ignored, and the others correspond with the usual suspects (age, serum creatinine, ejection fractice).
